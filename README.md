# Online Art Gallery System 🎨

## 📌 Description
The Online Art Gallery System is a web-based application designed to showcase and manage artworks in a digital gallery. It allows users to view, add, update, and delete artwork details with an easy and interactive interface.

## ✨ Features
- Add new artworks to the gallery  
- Update existing artwork details  
- Delete artwork entries  
- View all artworks in a clean gallery layout  
- Simple and user-friendly interface  

## 🛠️ Technologies Used
- React  
- Vite  
- JavaScript  
- HTML  
- CSS  

## 🎯 Project Objective
The main objective of this project is to create a digital platform where artworks can be managed efficiently using CRUD operations while providing a smooth user experience.
